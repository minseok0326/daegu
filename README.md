# 뜨거운 정류소

대구 시내버스 정류소 3,489곳의 한낮 승차 인원과 위성 지표면 온도를 겹쳐, 폭염에 가장 많이 노출되는 정류소를 찾은 데이터 분석·시각화 작품입니다.

2026 대구광역시 기후·환경·탄소중립 공공데이터 AI 활용대회 출품작(부문2 공공데이터 분석·시각화)

## 구성

- `index.html`: 웹 페이지 전체(지도, 그래프, 데이터, 글꼴이 한 파일에 들어 있어 인터넷 없이도 열립니다)

## 사용한 데이터

공공데이터포털(data.go.kr), 이용허락범위 '제한 없음'

- 대구광역시: 정류소별 시간대별 승하차인원, 버스 노선 공간정보, 시내버스 정류소 위치정보, 시내버스 정류소 목록, 정류소별 노선별 평균배차간격, 가로수정보, 시내버스 정류소 냉난방정보
- 대구교통공사: 1·2·3호선 역별 출구별 위치정보
- 산림청: 도시숲가로수관리 가로수 현황
- 질병관리청: 온열질환 감시 데이터

그 밖의 자료

- 통계청 통계지리정보서비스(SGIS) 행정동 경계(공공누리 1유형), vuski/admdongkor 저장소(CC BY 4.0)에서 내려받음
- USGS·NASA Landsat 8·9 Collection 2 Level-2 위성 영상(공공 도메인)
